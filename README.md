# Shalom Jeremiah — Digital Headquarters

A personal digital headquarters for technology, enterprise, writing, diplomacy and global affairs.

## Included

- Responsive Next.js App Router foundation
- TypeScript and custom CSS design system
- Midnight navy, electric cyan and silver visual identity
- Hero, About, Expertise, Projects, Enterprise, Global Affairs, Publications and Contact sections
- Responsive navigation and mobile menu
- GSAP, Three.js, React Three Fiber and Lucide React installed for future enhancements
- Project data separated into `src/data/projects.ts`

## Requirements

- Node.js 20.9 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build for production

```bash
npm run build
npm start
```

## First customizations

1. Replace the sample project descriptions in `src/data/projects.ts` with verified details.
2. Add your real portrait and project screenshots under `public/images/`.
3. Update social links and contact details in `src/app/page.tsx`.
4. Add a real contact form provider before publishing.
5. Review all biography and achievement statements for accuracy.

## Notes

This is a starter website, not a deployed site. It intentionally avoids invented awards, clients, metrics, testimonials or credentials. Add only achievements and project outcomes you can substantiate.
